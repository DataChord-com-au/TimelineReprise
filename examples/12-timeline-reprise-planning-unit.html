SIMILE Timeline Reprise: Planning Unit

This example uses Timeline.PlanningDayUnit. Day zero, numeric strings, ranges, labels, durations, bubbles, and a cardinal axis are handled by the same Reprise runtime.

  • the main band uses normal Planning day labels
  • one cardinal count is five Planning days
  • the cardinal band displays every second count: 0, 2, 4, and so on
  • both attachments inherit PlanningDayUnit from the band set
