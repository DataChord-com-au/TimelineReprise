SIMILE Timeline Reprise: Narrative

This example uses a narrative band beside the normal event band. Its plain data is parsed and rendered by the default Reprise presentation runtime.

Horizontal Timeline

  • the main band shows normal timeline events and ranges
  • the lower band uses chapter spans as decorator data
  • the Chapter 1 Narrative bubble constrains a deliberately oversized image

Vertical Timeline

  • the same main events and narrative data are shown vertically
  • the narrative band is still a separate decorator band
  • sticky span labels stack down their current column before using another column
